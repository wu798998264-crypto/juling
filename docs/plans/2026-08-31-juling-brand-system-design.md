# 聚灵品牌系统设计

## 目标

将工作副本中的应用品牌统一为“聚灵 / Juling”，替换旧 AGCT 图标、旧应用名称和带旧品牌的工程产物名，同时保持现有功能、按钮布局和用户数据兼容性不变。

## 视觉方向

- 主标名称：聚灵核心（Juling Core）
- 图形：三条轨迹向中心灵核汇聚，表达聚合、智能、精确与稳定。
- 配色：深青 `#155E63`、冰青 `#37C6D0`、雾白 `#DDF5F6`。
- 禁止元素：AGCT 字母、百分比滑杆、火箭、原版品牌文字。
- 小尺寸策略：应用图标使用带安全边距的彩色母版；托盘图标使用单色透明轮廓。

## 替换范围

1. Windows、macOS、iOS、Android、商店和安装包图标。
2. 系统托盘图标及设置页预览图。
3. 侧栏品牌图形、应用标题、托盘提示和 OAuth/报告等用户可见文字。
4. 工程目录和产物名：`juling-core`、`juling-cli`、`juling-cliproxy`、`juling_lib`。
5. 根目录文档与本项目源码中的旧品牌显示文字。

## 兼容边界

以下机器字段不能直接删除，否则会破坏旧数据和导入能力：历史数据目录、旧深链协议、历史导出 schema、旧环境变量以及外部服务约定的请求头。实现采用“聚灵新标识为主，旧标识仅作为兼容读取别名”的方式。第三方平台（Claude、Codex、Antigravity 等）的产品 Logo 不属于应用品牌，不做篡改。

## 验收标准

- 源码目录和构建产物不再使用旧品牌作为当前名称。
- 全套应用/托盘图标不含 AGCT、百分比滑杆或旧图形。
- 中文界面显示“聚灵”，其他语言显示“Juling”。
- 前端类型检查、语言包检查、Rust 检查、Go 测试和 Windows Release 构建通过。
- 实际启动窗口无白屏，侧栏、标题栏和任务栏显示新品牌。
