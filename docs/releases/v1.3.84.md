# 聚灵 S1.0.5 · 内部版本 1.3.84

同步 1.3.82—1.3.84 正式版功能与修复，提供 Windows x64 安装版、中文 MSI 和便携 ZIP。

## 本次更新

- 新增跨平台账号总览、额度趋势与历史清理、分组折叠排序、供应商模型测试和模型目录追加。
- Codex API 服务新增 Claude Code 配置预览与恢复、Key 思考深度上限、账号池唤醒、按额度重置时间调度、OAuth 模型映射和请求来源诊断。
- 同步账号、分组、实例、签到、唤醒、重置卡和显示偏好的本地数据库迁移；保留旧文件、账号顺序与已保存设置。
- 增强 Antigravity 无客户端唤醒和额度展示，支持 Cursor 浏览器令牌导入、Claude CLI 全局配置切换、SSH 多目标同步和 WorkBuddy 模型探测。
- 修复 DeepSeek 思考模式下并行工具调用续聊、Claude 凭据刷新与隐藏思考块、Copilot 授权错误提示和短窗口弹框滚动。
- 恢复第三方 Responses API Key 的默认直连，自动网关账号下次由聚灵启动时恢复供应商原始地址；手动网关与协议转换继续可用。
- 保留聚灵完整历史校验、冷却安全接替、全部已完成 exec 结果、工具不重放与重试总时间预算。

## 聚灵发行

- 保留聚灵界面、绿色标识、维护者 GitHub 与联系方式；原版广告、推广公告、反馈和原版更新后端继续关闭。
- 沿用聚灵独立仓库、应用标识和更新公钥。旧版可通过检查更新获取新版签名安装包。
- 数据迁移完成后，降级程序不等于回滚数据；覆盖安装前保留本地备份。
- Windows x64 更新签名用于验证安装包完整性。Windows Authenticode 签名尚未配置。
- Google、Gemini、Antigravity 自有 OAuth 构建凭据尚未配置，相应新授权流程仍需实际服务环境验证。
