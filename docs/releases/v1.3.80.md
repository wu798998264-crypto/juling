# 聚灵 S1.0.3 · 内部版本 1.3.80

同步 1.3.80 正式版功能，提供 Windows x64 安装版、中文 MSI 和便携 ZIP。

## 新增

- 支持 GPT-6.1 Terra 的模型目录、路由、唤醒预设、图片输入和测试，模型测试可选择 Ultra 推理档位。
- 接入 GPT Image 2.6 Sunburst、Flare 的原生 OAuth 图片接口，可在「模型与能力」配置生图模型及来源，支持图片编辑、复杂度、SVG 和 GIF 输出参数。
- Chat 供应商增加客户端工具发现与远程上下文压缩，生成的摘要可供后续请求复用。
- 新增重置卡自动使用规则、公共默认设置、触发预览和执行记录，处理重复兑换与结果不确定时的请求复用。
- 账号卡片支持拖拽排序，筛选、分页和备份导入保留对应账号的顺序。
- 2FA 增加搜索、筛选后全选、批量管理及本地迁移二维码导出，支持分页预览和 SVG 下载。
- API Key 编辑框增加完整密钥显示、隐藏和复制操作，重新打开时默认隐藏。

## 修复

- 改进 API 实例的新手引导状态、项目登记、会话归属与 Windows 项目分组恢复，修复历史索引备份刷新及会话排序。
- 额度刷新后清除已过期的额度冷却，保留新限额及其他冷却状态；Windows 网关端口被拒绝绑定时可重新分配并沿用原密钥。
- 请求排队期间重新检查账号冷却和备用账号，持续使用原等待预算；改善满载后的 HTTP 与 WebSocket 恢复。
- 修复续聊强制工具选择的重复继承、输入输出元数据兼容、图片能力保存和订阅有效期手动刷新。
- 保留聚灵完整历史验证、全部已完成工具结果、不重放工具及重试总时间预算。

## 发行说明

- 界面显示 S1.0.3，更新比较使用内部版本 1.3.80。沿用聚灵独立更新仓库、应用标识和更新签名。
- 聚灵品牌、绿色标识及维护者联系方式继续生效，广告、推广公告和原版反馈后端保持关闭。
- 本次发布 Windows x64。更新签名用于安装包完整性验证，Windows Authenticode 签名尚未配置。
- Google、Gemini、Antigravity 自有 OAuth 构建凭据尚未配置，相应新授权流程需在实际服务环境下验证。
- 2FA 迁移二维码包含所选账号的动态码密钥，请仅交给你要迁移到的验证器。
