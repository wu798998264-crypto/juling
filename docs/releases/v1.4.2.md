# 聚灵 S1.0.7 · 1.4.2

- Codex 新增命名账号池、客户端 Key 绑定、月度 Token 提醒、输入字符统计和请求日志筛选。
- 新增 GPT-6.2 Sol／Astra 目录及成本估算，支持手动与后台刷新。同步 Ollama 和 Requesty 供应商预设。
- Codex 桌面和 CLI 可指定会话续跑，新增子代理默认模型和本地系统指令设置。Codex 重置卡改为手动确认兑换，既有记录可查看。
- Antigravity 新增本地会话 Token 统计，并改进额度分组。WorkBuddy 可重绑改名工作区的会话。
- 设置可选择数据目录，重启后生效。Windows 修复进程检测、代理与托盘菜单；macOS 可设置菜单栏点击动作，并改进 Qoder 钥匙串及 Claude 登录态保存。
- 保留聚灵的完整历史校验、冷却安全接替和全部工具结果。重试仍受原请求的总时限约束。

Windows 提供安装版、MSI 和便携 ZIP。Mac 提供 Apple 芯片、Intel 和通用 DMG，支持 macOS 12 或更新版本。Mac 包使用临时签名，未进行 Apple 公证。两平台的自动更新均沿用聚灵的签名公钥与仓库。原版推广和反馈渠道保持关闭，随包保留来源许可说明。Google、Gemini 和 Antigravity 新登录使用独立 OAuth 凭据，发行仓库尚未配置这些凭据。
