# 聚灵 S1.0.9 · 1.5.3

- 批量生图补齐请求的张数，并合并用量记录。每次补图受原请求总时限约束。
- Codex 号池可为单个账号设置并发上限。留空沿用全局设置，1–64 限制同时处理的请求数，0 表示不限。
- Codex 会话用量支持按小时查看当天趋势。匹配到本机 API 记录时，请求详情会显示首字延迟和输出速度。
- Antigravity 会话详情增加逐轮上下文、缓存拆分和压缩标记。用量面板增加参考费用和活动热力图，套餐及额度分组兼容最新命名。
- 中转站可为选定密钥预览并写入 Gemini CLI 配置。预览和保存均使用用户确认的服务地址。新增 Codex 和 Claude 供应商预设。
- T3 Code 常用设置可控制用量分析、连接追踪和活动推送。隐私选项可在下次启动默认实例时生效。
- 窄窗口中的账号分组可换行，侧栏空间不足时可滚动。优化大请求压缩的内存占用以及严格 Chat 接口的字段兼容。

Claude Desktop 继续使用聚灵原有的授权流程。本轮同步范围以上述功能为准。
