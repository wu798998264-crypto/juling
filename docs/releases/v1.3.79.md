# 聚灵 S1.0.2 · 内部版本 1.3.79

同步最新正式版功能，提供 Windows x64 安装版、中文 MSI 和便携 ZIP。聚灵独立更新地址与签名公钥继续有效。

## 更新内容

- 新增 MiniMax Code 账号接入、导入、多开、积分查询与签到；TRAE 国内版和 SOLO 国内版增加签到状态、自动签到和执行记录。
- 可关闭单个平台的自动刷新、令牌保活、唤醒和签到，并保留手动操作；新增减少动画选项及账号切换／刷新时间显示偏好。
- Codex 更新模型目录与原生下一步预测兼容，支持为用量查询单独配置管理员 Key，模型调用继续使用原有 API Key。
- API 服务遵循单个 API Key 的代理设置，改善满载恢复、额度换号、共享网关 WebSocket 与首响统计。
- 保留聚灵冷却安全接替：完整历史及全部工具结果验证通过才允许接替；历史不足时保留原账号，已执行工具不重放，重试继续受总时间预算约束。
- 改进 WorkBuddy 积分明细、Antigravity 桌面／IDE 共享登录、Cursor 周额度、Claude 商店版资料识别和 Codex 切号进程退出。
- 附带按需使用的本地项目恢复与 Windows 沙箱诊断工具；升级不会自动运行这些恢复操作。

## 聚灵发行策略

- 保留聚灵界面、绿色品牌、你的 GitHub 与联系方式；原版广告、活动入口、原作者宣传链接、推广公告和反馈后端继续关闭。
- 沿用独立更新仓库与签名，不批量改写用户保存的服务地址、凭据和模型。
- 保留 HTTPS 订阅和同源跳转限制，本地／内嵌 provider 及离线许可策略。
- 本次发行 Windows x64。更新签名不等同于 Windows Authenticode 代码签名。
- 沿用现有 OAuth 构建配置；Google/Gemini/Antigravity 自有 OAuth 构建凭据尚未配置时，相应新授权流程仍不在完整实机验收范围。第三方账号权限和网络会影响实际服务能力。
