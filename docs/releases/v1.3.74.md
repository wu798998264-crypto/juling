# 聚灵 S1.0 · 功能基线 1.3.74

同步上游 2026-10-24 的 1.3.74 发布提交 054867e5d6f15ba03c48796bc97cdb2cd359247e。保留聚灵皮肤、绿色品牌、独立更新源及广告过滤，不恢复推广、反馈或原版遥测后端。

## 本次更新

- 新增“修复会话索引”：会话管理和启动预览都可进入。检查所选会话及祖先记录，在原始记录完整且客户端已退出后备份并重置越界分页索引；不重写聊天记录、账号和 Provider 设置。
- API 服务及成员设置新增“会话 ID 映射”，默认开启。关闭后透传客户端的 Session-Id / Thread-Id；两种切换方向均需确认说明，再保存设置生效。
- 支持压缩会话的显示、恢复、导出与同步；恢复、导入保留并发新记录，补索引可安全重试，客户端拒绝删除分支引用记录时保留恢复备份。
- 适配新版 Codex 速度控件、额度、Astra 提问弹框和 clock 工具；修复多输入框/模型菜单的会话状态串用、批量勾选计数、CLI 预览启动、Windows 配置路径与 MSIX 启动。
- 同步 Rust/Go API 服务的旧会话、工具历史和新版消息兼容修复，保留权限隔离、防重复执行和上游原始错误；Rust 代理故障信息区分超时、代理不可达及真实认证失败。
- Antigravity 额度增加 Gemini 4 Argon Weekly，并以单列五个窗口展示；授权参数、原生请求头、15 分钟提前刷新和一次短暂退避重试对齐上游，回调支持 IPv4/IPv6。
- 修复 UTF-8 BOM 账号文件、安全备份恢复、并发存储及桌面凭据回退同步；保留 id_token、有效备份和较新备注。修复 Codex 用量弹框读取重试和账号统计闪烁。
- 补充 Windows 会话索引修复的备份落盘兼容：仅对新生成的备份使用可写刷新句柄，备份验证成功后才处理派生索引，不重写原始会话记录。

## 安装与更新

Windows 10/11 x64：安装包为 Juling_1.3.74_x64-setup.exe，便携包为 Juling_1.3.74_x64-portable.zip。覆盖安装只替换程序，不重置账号、API 地址、协议、模型或客户端偏好。

沿用聚灵 1.3.73 的独立 updater 公钥；更新只访问 wu798998264-crypto/juling，不连接上游更新仓库。便携 ZIP 用于手动解压，自动更新资产为带签名的 NSIS。

## 已知限制与许可

- TypeScript、发布工具、Rust core、Go 主模块及本次桌面增量回归已验证；Windows 备份 13 项、代理错误 7 项、Rust/Go 对照 23 项通过。扩大桌面/第三方整包仍有既有 Windows 文件锁、路径、时间戳及耗时相关测试失败，不能视为全套测试全绿；真实账号与付费请求未验收。
- 本次只提供 Windows x64 包；macOS/Linux 相关源码同步不代表已在这些平台构建或验收。
- updater 已签名不等同于 Windows Authenticode 商业证书；未做 Authenticode 时系统仍可能提示风险。
- 维护者自有 Google/Gemini/Antigravity OAuth 客户端配置尚未提供，没有提取原版隐藏凭据；Codex 官方公共 OAuth ID 保持兼容。真实账号授权和付费请求未做全链路验收。
- Mihomo 不随包。历史原版可能共享账号目录，避免同时操作同一客户端。程序备份不等于账号数据回滚。
