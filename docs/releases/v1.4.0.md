# 聚灵 S1.0.6 · 内部版本 1.4.0

同步 1.4.0 正式版功能与修复，提供 Windows x64 安装版、中文 MSI 和便携 ZIP。

## 本次更新

- 新增 WorkBuddy AI 国际版账号管理；Antigravity 桌面版、IDE 与 CLI 统一启动，CodeBuddy 系列支持 CLI 与独立实例。
- 新增代理 DNS／IPv6 配置、平台拖拽及键盘排序、账号与模型组合批量探测、双窗口切号阈值和更多供应商额度查询。
- 改进长会话历史分段预载、额度拦截恢复、失效网络连接重连；预载结果未知时不自动重放。保留全部已完成 exec 结果和聚灵安全接替、工具不重放及重试总时间预算。
- 修复 Windows 服务停止后的端口占用、API Key 协议保存、套餐与积分展示、压缩会话用量以及 MiniMax 共用凭据续期。
- 会话和项目修复保留历史备份，移除固定处理上限；优化浅深主题、账号卡片、侧栏、短窗口弹框和下拉交互。

## 聚灵发行

- 保留聚灵界面、绿色标识、维护者 GitHub 与联系方式；原版广告、推广公告、反馈和原版更新后端继续关闭。
- 沿用聚灵独立仓库、应用标识与更新公钥，旧版可通过检查更新获取新版签名安装包。
- 覆盖安装前保留账号数据和程序备份；程序降级不等于数据迁移回滚。
- Windows x64 更新签名用于验证安装包完整性。Windows Authenticode 签名尚未配置。
- Google、Gemini、Antigravity 自有 OAuth 构建凭据尚未配置；相应新授权及真实账号服务需在具备凭据的环境验收。
