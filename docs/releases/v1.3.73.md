# 聚灵 S1.0 · 功能基线 1.3.73

- 同步多平台账号管理、模型配置、会话、额度保护、账号测智和代理能力。
- 更新 Rust 原生 API 服务与 Go 辅助代理，保留聚灵皮肤和 S1.0 界面版本。
- 过滤原版顶部广告、推广公告与反馈提交后端；中转台需用户明确配置地址。
- 不自动替换用户保存的账号、密钥、服务地址或协议。
- 建立聚灵独立更新签名和 Windows NSIS 更新包；检查更新只访问本仓库。

## 下载与升级

Windows 10/11 x64：`Juling_1.3.73_x64-setup.exe` 为安装包，`Juling_1.3.73_x64-portable.zip` 为完整便携包。
保留账号数据后覆盖安装旧聚灵。这次是独立签名信任的首次迁移，旧版不能自动信任新签名；后续发行须沿用本次密钥。便携包不是 updater 的安装资产。

本次仅发行 Windows x64，不宣称已提供 macOS/Linux 安装包。
安装包具备聚灵 updater 校验签名，但尚无 Windows Authenticode 商业证书，可能出现系统安全提醒。

## 已知限制

Google/Gemini/Antigravity 自有 OAuth 客户端配置尚未提供，相关授权需要维护者另行配置。没有提取原版隐藏凭据。Codex 官方公共 OAuth 客户端保留。
Mihomo 未捆绑，需要用户合法取得后主动配置。真实账号授权和付费模型请求未作全链路验收。
历史账号目录可能与原版共享，不建议同时操作同一客户端配置。程序备份不等同于账号数据回滚。

源码及离线第三方许可声明随发行提供；来源与许可见 NOTICE.txt。
