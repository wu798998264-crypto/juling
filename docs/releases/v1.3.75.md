# 聚灵 S1.0 · 功能更新 1.3.75

同步上游 2026-10-27 稳定版 1.3.75，固定提交 2cfe5e51314bfc0bf70bdda1ba08aed82c7dc8bf。保留聚灵布局、绿色品牌、独立更新签名及广告过滤。

## 本次更新

- 新增 GPT-6.1 Terra 模型与标准、Fast、Flex、长上下文费用估算适配。费用为本地估算，实际结算以服务商账单为准。
- 设置新增四款渐变和本地图片背景，支持强度、模糊、图片位置与恢复默认，修改即时生效，仅保存本机。
- Codex 额度到期明细增加缓存、定时分散刷新及详情联动；优化 New API 卡片剩余额度进度条。
- 同步 Antigravity 的 Gemini 4 Argon、Gemini 3.8 Flash、Claude 5.5 分组和 Ultrafast 速度选项。自动切号按实际返回分组判断额度。
- 修复单个请求取消误重启共享代理的问题，改善多代理工具命名空间、Gemini 请求错误分类和第三方模型路由兼容，保留 Reserve。
- Kiro 支持 IAM Identity Center JSON 授权与令牌刷新；Claude Desktop Gateway 切号保留隐私、权限、网络和模型设置，写入失败可恢复。
- 优化 Windows 启动确认、客户端路径缺失恢复和取消流程，避免取消后重复启动；改进开发实例退出清理。
- 历史索引模式支持客户端运行时修复：事务内检查并发变化，先备份再处理派生索引，不重写原始聊天记录。保留聚灵 Windows 备份刷新兼容修复。
- 数据管理页首次访问后保留已挂载内容，切换标签不丢失页面状态。

## 安装与更新

Windows 10/11 x64：Juling_1.3.75_x64-setup.exe；便携版：Juling_1.3.75_x64-portable.zip。覆盖安装只替换程序资源。账号、API 地址、模型和客户端偏好沿用现有配置。

检查更新继续使用 wu798998264-crypto/juling 和已有独立公钥。已接入该更新源的旧版可检查更高功能版本；自动更新使用签名 NSIS，便携 ZIP 供手动解压。

## 聚灵适配与限制

- 移除上游新增的供应商推广皮肤，统一继承聚灵卡片样式；不改用户真实 API 地址。广告、公告、反馈后端保持禁用，界面版本继续 S1.0。
- 本次提供 Windows x64 包；其他平台源码同步不代表已构建验收。真实账号授权和付费模型请求不纳入自动回归。
- 自有 Google/Gemini/Antigravity OAuth 客户端配置仍待提供；没有提取原版隐藏凭据。Mihomo 不随包。
- updater 签名沿用独立信任，不等于 Windows Authenticode 商业代码签名。
- 历史原版可能共享账号目录，避免同时操作同一客户端；程序备份不等于账号数据回滚。
