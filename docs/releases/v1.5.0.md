# 聚灵 S1.0.8 · 1.5.0

- T3 Code 可集中管理本机账号、默认账号和额度。支持的 Antigravity、Codex 会话可查看上下文占用和输出速度。
- 新增 Qoder CN 及独立加密账号存储。CLI 支持查询账号、额度、切换账号和管理 API 服务成员。
- Codex 会话用量增加模型、实例、项目筛选。本机 API 和模型目录可通过已配置的 SSH 连接同步，关闭同步时恢复原配置。
- 新增供应商预设、到期积分提示和 macOS 双行额度菜单。改进窄窗口工具栏、客户端路径选择和批量导出预览。
- 修复 Windows 客户端识别与代理设置、macOS 外接屏窗口恢复、ChatGPT 启动和 Codex 压缩历史索引问题。
- 聚灵继续校验完整会话历史。冷却接替时保留已完成工具调用的全部结果，重试受原请求总时限约束。

Windows 提供安装版、MSI 和便携 ZIP。macOS 12 或更新版本可选 Apple 芯片、Intel 和通用 DMG，应用使用临时签名。自动更新继续使用聚灵仓库和原签名密钥。Google、Gemini 和 Antigravity 新登录，以及在 T3 Code 中接入 Antigravity，均需要配置聚灵自己的 OAuth 凭据。当前发行包未预置相关凭据。
