# 聚灵 S1.0.4 · 内部版本 1.3.81

同步 1.3.81 正式版修复，提供 Windows x64 安装版、中文 MSI 和便携 ZIP。

## 修复

- 切号后手动打开客户端时恢复同一实例中可核验的本地项目。项目分组优先恢复，项目归属与官方客户端的 OAuth 用户和工作区一致。
- 应用运行期间每小时刷新 OAuth 账号的订阅有效期，按账号错峰查询，可在旧日期到期前识别续订结果。
- 同一账号自动使用重置卡成功后，至少间隔 30 分钟才可再次自动用卡，应用重启后继续计时。
- 个别会话文件或祖先历史缺失时，其余会话仍可修复索引。预览和结果列出受影响 ID 与缺失来源，并保留受影响数据。
- 大型会话日志采用分块扫描，解除历史索引预览和修复的固定文件、记录及累计读取字节限制。
- 进程探测返回桌面界面目录时，仍能从官方默认认证目录同步同一账号的较新凭据。
- API 端口冲突弹框可选择清理当前端口或切换随机可用端口，清理失败后也能直接更换。

## 聚灵发行

- 界面显示 S1.0.4，版本比较使用 1.3.81，沿用聚灵独立仓库与更新签名。
- 保留聚灵界面、绿色标识和维护者联系方式，广告、推广公告及原版反馈后端继续关闭。
- 保留冷却安全接替、完整历史校验、已完成工具的全部结果、工具不重放与重试总时间预算。
- Windows x64 更新签名用于验证安装包完整性。Windows Authenticode 签名尚未配置。
- Google、Gemini、Antigravity 自有 OAuth 构建凭据尚未配置，相应新授权流程仍需实际服务环境验证。
