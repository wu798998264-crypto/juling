# 聚灵 S1.0.1 · 内部版本 1.3.78

同步原版 Cockpit Tools v1.3.78 稳定版，保留聚灵品牌、独立更新渠道和签名公钥。提供 Windows x64 EXE、中文 MSI 和便携 ZIP；不覆盖已发布的旧版资产。

## 更新日志（中文）

## [1.3.78] - 2026-11-03

### 新增
- 局域网共享网关：通过用户配置的服务地址和 API Key 发现模型、推理档位及图片能力，查看自身 Key 的预算、用量和请求记录。
- 用量预算：支持总额及日／周／月周期，提供每日金额、图片请求次数和并发上限。金额是按服务端价格估算的使用额度，不是充值余额。
- 设备限制：识别明确的官方设备限制错误，暂停相关重试并支持人工处理；清除本地记录不代表释放服务端名额。

### 修复与优化
- 合入 Claude、Kiro、Cursor、Qoder、WorkBuddy、ZCode、TRAE 等客户端凭据与额度兼容修复，失败时保留已有有效数据。
- 改善大历史数据下的账号查询、日志索引和用量统计，后台分批维护，不清空账号或聊天记录。
- 更新原生速度控件和 Ultra 档位兼容，保留已有模型来源、用户配置及真实鉴权错误。
- 更新说明默认使用随包及安装时保存的内容；保留可显式调用的聚灵独立仓库说明接口，不改变自动更新信任。
- 保留中文 MSI 云构建修复，NSIS 继续作为 Windows 默认自动更新渠道。
- 更新 Mihomo 1.19.33 的固定版本与校验信息，保留用户主动安装、默认不捆绑的分发策略。

### 去广告与安全边界
- 不导入原版双十一推广区、活动角标、推广链接、社区二维码及推广公告；三套供应商预设继续使用通用展示。
- 不改写用户已保存的 API 地址、账号密钥和模型配置。保留原版互通协议标识与第三方许可证。
- 订阅下载维持 HTTPS、无 URL 内嵌凭据和同源受限跳转。原生配置仅使用本地文件／内联 provider；不启用远程 provider、远程 UI 或 geodata 下载。远程节点集合需先本地化；规则集合仅支持 domain／ipcidr，classical 及 GEOIP／GEOSITE／IP-ASN 规则需先转换为域名／IP 规则。本限制也适用于旧缓存恢复。

## Changelog (English)

## [1.3.78] - 2026-11-03

### Added
- LAN gateway discovery, per-key budgets, usage and request views, plus explicit device restriction reporting.

### Fixed
- Import upstream credential/quota compatibility, incremental local-data maintenance and native speed-control fixes.
- Preserve Chinese MSI packaging and the signed NSIS default updater channel.
- Use bundled/installation-time notes by default while retaining explicit independent-repository release-note APIs.

### Distribution policy
- Exclude promotional campaigns, affiliate entry points and remote announcements; retain neutral provider presentation and saved user endpoints.
- Keep HTTPS-only subscription downloads with same-origin bounded redirects and no URL userinfo. Native providers must be local or inline; remote provider, UI and geodata downloads remain disabled. Rule providers must explicitly use domain or ipcidr; convert classical and GEOIP/GEOSITE/IP-ASN rules to domain/IP rules first. Cached profiles are revalidated under the same policy.
- Keep Mihomo optional and preserve upstream wire compatibility and third-party notices.

## 使用范围

- Windows x64 发行；macOS/Linux 仅参与本轮构建检查，不在此发布。
- 安装包带 Tauri updater 签名，不等同于 Windows Authenticode 代码签名；未签名 EXE 可能仍触发 SmartScreen 或 Smart App Control。
- 真实服务可用性取决于网络、账号权限、凭据及服务端能力。新远程服务视图需两端升级并重启对应客户端实例。
- Google/Gemini/Antigravity 自有 OAuth 构建凭据未配置时，相应新授权流程不可视为已验收；已有授权数据不会被本次同步批量改写。
