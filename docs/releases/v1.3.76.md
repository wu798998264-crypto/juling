# 聚灵 S1.0.1

Windows x64 正式版。内部版本 1.3.76，沿用聚灵独立仓库、应用身份及更新签名公钥，旧版可通过“检查更新”获取此版本。

## 更新日志（中文）

## [1.3.76] - 2026-10-31

### 新增
- Anthropic Messages 接入：可选择鉴权方式，获取或手动填写模型目录，支持流式回复、工具、网页搜索和上下文压缩，实际能力取决于所配服务。
- OpenAI 官方 API 用量：按 UTC 查看消费、请求数和 Token；权限不足时提供管理员密钥指引，消费金额与余额分别展示。
- 本地项目与会话修复：提供快速修复、历史快照、索引恢复、本地备份和中断恢复，保留云项目、凭据及聊天正文。
- 我的皮肤：保存、切换、重命名、更换和删除本地背景，每张图片独立保存显示参数。
- 请求体积诊断：无需保存正文即可查看历史、工具与指令体积，辅助排查大请求和账号满载。

### 变更
- API 服务统一使用内置 Rust 引擎，兼容旧引擎配置并保留账号、密钥、端口和历史，不再分发 Go sidecar。
- 账号与供应商共用完整编辑器，可分别设置供应商默认模型及每个 Key 的模型，保留绑定和同步设置。
- 继续使用聚灵绿色品牌和通用卡片；作者、仓库、赞助二维码保留维护者信息，广告、推广公告与原反馈后端保持关闭。
- 更新弹框从聚灵自己的 Release 获取说明，沿用既有签名信任。

### 修复
- 改善 Responses、SSE、WebSocket 续接、额度恢复、满载重试与 HTTP/2 连接恢复；已有输出或工具执行迹象时不自动重放。
- 适配新版 Codex Fast 控件、Terra Ultra 与 DeepSeek Responses，保留用户模型目录和上下文设置。
- 后台刷新保留供应商、端口、代理、密钥、调度与模型等未保存编辑；保存失败仍可在弹框内重试。
- 改善 Token 统计、启动配置预览、Antigravity 额度和唤醒兼容。

## Changelog (English)

## [1.3.76] - 2026-10-31

### Added
- Anthropic Messages with model discovery, configurable authentication, streaming, tools, search and compaction, depending on provider support.
- Official OpenAI API spend, request and token statistics in UTC, with usage-permission guidance.
- Local project/session repair with backups and interrupted-write recovery, plus a per-image local skin library and request-size diagnostics.

### Changed
- API Service uses the embedded Rust engine exclusively and migrates old engine selections without replacing saved account, key, port or history settings.
- Shared provider editing with per-key model configuration. Independent Juling branding, contact links and updater trust remain in place; promotion services remain disabled.

### Fixed
- Safer continuations, capacity/quota recovery, HTTP/2 fallback and current Codex Fast compatibility. Requests with output or tool-execution evidence are not automatically replayed.
- Preserve unsaved edits during background refresh and retain model catalogs and context settings.

## 使用与范围

- 提供 Windows x64 安装包和便携 ZIP；本次不发行 macOS/Linux 安装包。
- 安装程序附带聚灵 updater 签名，Windows EXE 尚无 Authenticode 证书签名。
- 用户现有账号、API 地址、密钥及模型不会在本次同步中批量改写。第三方协议与历史兼容标识按实际语义保留，来源和许可见 NOTICE.txt。
- Google/Gemini/Antigravity 自有 OAuth 凭据尚未配置；Mihomo 不随包。真实服务可用性取决于用户网络、凭据、权限和上游能力。
