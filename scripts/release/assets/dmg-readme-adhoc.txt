聚灵 macOS 安装说明

把“Juling.app（聚灵）”拖入 Applications（应用程序），再从应用程序文件夹打开。
Apple 芯片使用 aarch64，Intel 使用 x64；universal 同时包含两种架构。

本安装包采用 ad-hoc 临时签名，尚未进行 Apple Developer ID 签名或公证。
临时签名与聚灵更新签名用于完整性校验，不等于 Apple 已审核此软件。
首次打开时 macOS 可能提示无法验证开发者。请先核对下载来源与校验值，
再按 Apple 的官方说明决定是否允许打开：
https://support.apple.com/zh-cn/102445
不要直接把“已损坏”或恶意软件警告当成误报，也不要关闭系统安全保护。

下载与反馈：https://github.com/wu798998264-crypto/juling/releases
维护者：https://github.com/wu798998264-crypto
